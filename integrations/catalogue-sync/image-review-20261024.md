### Media publishing gate
Record `source_url`, `rights_holder`, `license`, `is_illustrative`, `variant_sku`, `pack_size`, `approval_status`, `approved_by`, `approved_at`, file checksum. Images with unverified rights or variant mismatch must stay private. Push approved media using the same canonical ID through Books/Commerce/Catalyst, and reconcile each destination ACK. A generated image must visibly state that it is an illustrative representation, not an exact factory package.
